# Application-Systems-Development

## Short Description
MedStudy System is a web-based study room reservation platform designed for the School of Medicine (SOM) Library. It allows students to check room availability, book study spaces, and manage reservations conveniently online. The system features real-time scheduling, automated notifications, and access control to ensure efficient and fair room usage. Administrators can monitor bookings, generate reports, and enforce policies to optimize study room management. MedStudy streamlines the reservation process, reduces scheduling conflicts, and enhances the overall study experience for medical students.
